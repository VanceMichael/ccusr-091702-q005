# 季节权益兑付清算服务

本服务用于提货权益发行、转赠、核销、召回与周期清算。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：发行批次、权益、持有人、门店、核销尝试、交付、裁决、结算期。

部分兑付遵守余额守恒；重复扫码返回原结果；冻结调查期间禁止交付；封账后的更正进入下一结算期。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/seasonal_entitlement.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
